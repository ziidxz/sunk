Sunk, offline edition
=====================

Thank you for buying Sunk. This folder has two files:

  sunk-offline.html   the whole app, __SIZE__, no installation
  README.txt          this note

Open sunk-offline.html in a browser. Double-clicking the file is enough.
There is no account, no activation, and no network connection required.

Your ledger
-----------

Sunk saves your entries in the browser you open the file with. It does not
send them anywhere. That also means:

  - A different browser has a different ledger.
  - Clearing the browser's site data can delete the ledger.
  - A private or incognito window may discard it when closed.

Download a JSON backup from Settings whenever the ledger matters. Restoring a
backup replaces the current ledger, after a confirmation.

Moving the file
---------------

You can move the HTML file, keep it on a USB stick, or email it to yourself.
Your ledger is tied to the browser, not to the file's location. If you open the
same file in the same browser, the entries are still there.

Some browsers block storage for local files. If Sunk shows a red warning that
the ledger is not saving, open the file through a small local server or use a
browser that permits storage for file URLs. The backup file is the safe copy in
every case.

What the offline edition adds
-----------------------------

  - Unlimited subscriptions, instead of five.
  - CSV import. Download a statement from your bank or card, choose the file,
    match the columns, and Sunk proposes repeating charges.
  - Renewal and trial reminders as an .ics file, with a three-day warning.
  - Every feature of the free web edition, including JSON backup and restore.

The CSV file is read in your browser. It is never uploaded. The .ics file is
created on your device and can be imported into the calendar you already use.
